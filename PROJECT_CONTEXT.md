# Контекст проекта: Вращающиеся фигуры (мультиплеер)

## Цель проекта
Веб-приложение с интерактивными фигурами: при клике фигура поворачивается в
следующее положение (например, +90°), и это изменение видно в реальном
времени всем удалённо подключённым пользователям.

Это НЕ приложение внутри Miro — отдельный самостоятельный веб-сервис
(изначально рассматривали Miro Web SDK, но решили делать отдельно).

## Формат работы
Образовательный проект — Claude объясняет теорию и пишет код вместе с
пользователем, построчно, с разбором каждой части (а не просто выдаёт
готовый код).

## Уровень пользователя
- Python: сильный (numpy/расчёты/графики), но НЕТ опыта с веб-бэкендами
  (лёгкий опыт с FastAPI был давно, почти забыт)
- HTML/CSS/JS: с нуля, не знает вообще
- Инструменты: PyCharm (сейчас глючит — Settings не открываются),
  венвы использует регулярно
- ОС: Windows, работает в cmd

## Архитектура (согласовано)
```
Браузер (клиент) <--WebSocket--> Python-сервер (FastAPI) <--WebSocket--> Браузер (клиент)
```
Сервер хранит состояние (углы поворота фигур) как единый источник правды.
Клик в браузере -> сообщение по WebSocket серверу -> сервер обновляет
состояние -> рассылает всем подключённым клиентам -> все видят синхронно.
